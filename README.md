International Space Station Website

A responsive multi-page website about the International Space Station, created as part of a university Web Design module.

Pages

* Home
* History
* Life Aboard
* Research
* Contact

Technologies Used

* HTML5
* CSS3
* JavaScript

Features

* Responsive design for desktop and mobile
* Fixed navigation bar
* Mobile navigation menu
* Multiple pages with consistent navigation
* Information about the ISS and its history
* Research and educational content
* Contact form
* References and external resources

Project Purpose

This project was created to develop my skills in web design and front-end development, including HTML structure, CSS styling, responsive design and basic JavaScript functionality.

Sources

Information was researched using sources including NASA, the ISS National Laboratory, Space.com and Britannica.
